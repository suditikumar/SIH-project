# 🧠 Cognitive Companion for Dementia Care

### Smart India Hackathon (SIH) Project

An interactive, multilingual and offline-first cognitive companion designed to support people with dementia through **cognitive games, conversational interaction, memory assistance, and personalized daily support**.

---

## 🎯 Our Aim

Our aim is to develop a simple and engaging digital companion that can help people with dementia maintain cognitive engagement, remember important daily activities, and interact naturally in a language they are comfortable with.

Instead of relying on a single clinical or complicated interface, our solution combines **cognitive games + conversational assistance + reminders + multilingual interaction** into one accessible platform.

---

# 💡 Our Solution

The solution consists of two major parts:

### 🎮 1. Cognitive Games

We provide four different cognitive games targeting different areas of cognitive functioning:

- 🧠 Memory Game
- 🔢 Numbers Game
- 🔤 Word Puzzle
- ✏️ Scribble Game

These games are designed around the four cognitive domains mentioned in the SIH problem statement:

| Cognitive Domain | Our Approach |
|---|---|
| Memory | 🧠 Memory Game |
| Attention & Concentration | 🔢 Numbers Game |
| Daily Routine Recall | 🔤 Word Puzzle / recall-based activities |
| Pattern & Object Recognition | ✏️ Scribble Game |

The difficulty of the activities can be adapted according to the user's performance, allowing the experience to become more suitable for the individual over time.

---

# 🗣️ 2. Conversational AI Companion

Alongside the games, we are developing a **voice-assisted conversational AI companion**.

The user can interact with the companion naturally instead of having to navigate complicated menus.

The companion is intended to help with:

- 💬 Natural conversation
- 🔔 Reminders
- 🧠 Memory assistance
- 🎮 Guiding users toward cognitive activities
- 🗓️ Daily routine support
- 🌐 Multilingual interaction

### 🌏 Multilingual Support

A major part of our solution is making the companion accessible in multiple languages.

The system is designed to support **multiple Indian languages, including languages spoken in Northeast India**, so that users can communicate in a language that is familiar and comfortable to them.

This is especially important for elderly users who may not be comfortable communicating in English or navigating conventional technology.

---

# 🔔 Memory & Reminder Assistance

The platform includes a memory-assistance component that can help users remember important aspects of their daily lives.

Reminder categories include:

- 💊 Medicines
- 💧 Hydration
- 🏠 Daily activities
- 🏥 Medical appointments

The conversational companion can interact with the user around these reminders, making them feel more natural than simply displaying notifications.

# 🎮 Cognitive Games

## 🧠 Memory Game

A visual memory game where users recall and match information.

**Targets:**
- Memory
- Recall
- Concentration
- Visual recognition

---

## 🔢 Numbers Game

A number-based cognitive activity involving simple numerical challenges, sequences, matching, or recall.

**Targets:**
- Attention
- Concentration
- Logical thinking
- Numerical recall

---

## 🔤 Word Puzzle

A language-based cognitive activity involving words, recognition, recall, and associations.

**Targets:**
- Language recall
- Recognition
- Concentration
- Memory

The game can be adapted to different supported languages.

---

## ✏️ Scribble Game

An interactive drawing and recognition activity where users can scribble, draw, or reproduce simple visual patterns and objects.

**Targets:**
- Pattern recognition
- Object recognition
- Visual processing
- Hand-eye coordination

---

# 🧩 Adaptive Difficulty

The games are designed to be adaptive rather than having the same difficulty for every user.

The system can consider the user's performance and adjust future activities accordingly.


User plays a game
       ↓
Performance is recorded
       ↓
Cognitive score is calculated
       ↓
Difficulty is adjusted
       ↓
Next activity is personalized
